Moth Desktop 0.3.6 adds full-policy preview and import for supported Clash YAML, named proxy groups, providers, rule sets, DNS and dialer-proxy chains via pinned Mihomo. The owner can select a group member while connected. Failed refreshes preserve the last validated profile. Clash policy mode requires the kill switch to be off. The complete 0.3.6 package is required for these features. See the release notes and docs/CLASH.md for supported fields and limitations.
