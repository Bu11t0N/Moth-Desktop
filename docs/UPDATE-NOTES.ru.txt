Moth Desktop 0.3.4

Subscriptions by URL with per-source HWID/device consent, quota metadata, scheduled and VPN-only refresh. Added library search/favorites/sorting, supported JSON/Clash imports and additional typed profile families. Unsupported options fail explicitly; paid-provider compatibility is provider-specific.

Connection policies, executable-path splitting, optional recovery/health/failover, encrypted backups and compatible Android v1 migration with preview. Light/dark/system themes and Russian/English UI. Fixed Russian installer/uninstaller and license text.

Install the complete package for new service features. Existing protected storage, pinned engines and production updater signatures are retained. No persistent kill switch or full Android parity; ordinary networking can return after failure. No general proxy/LAN, traffic telemetry or OS login autostart. Windows x64 requires WebView2; Linux support is limited to Ubuntu 24.04 x64.
