Moth Desktop 0.3.2 добавляет системный трей и привычное поведение VPN-клиента при закрытии окна.

- Крестик скрывает окно в трей и сохраняет VPN-подключение.
- Левый щелчок по значку или повторный запуск ярлыка открывает существующее окно.
- Правый щелчок открывает меню: «Открыть Мотылёк», состояние VPN, «Отключить VPN», «Выход».
- «Выход» сначала отключает принадлежащий пользователю VPN и дожидается подтверждения службы, затем завершает приложение. Если отключение не подтверждено, приложение остаётся в трее и показывает ошибку.
- Значок и состояние обновляются нативно, даже при скрытом окне. Повторный запуск не создаёт второе приложение.

Уже установленная служба 0.3.1 совместима с этим обновлением: переустанавливать её не требуется. В Windows значок нового приложения может оказаться под стрелкой скрытых значков рядом с часами.

Проверено на нативном окне Windows: значок в скрытых значках, закрытие крестиком с сохранением процесса и восстановление того же окна вторым запуском. На изолированной Windows VM проверены те же действия с реально работающим VPN и отключение туннеля через обработчик «Выход». Windows/Linux CI: https://github.com/Bu11t0N/Moth-Desktop/actions/runs/43450775552.

Сборка для разработки без цифровой подписи. Ограничения 0.3.1 сохраняются: kill switch и автоматическое переподключение после смены сети/сна ещё не реализованы.
