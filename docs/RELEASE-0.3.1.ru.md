Moth Desktop 0.3.1 добавляет системное VPN-подключение в Windows x64 через выбранный сервер VLESS/Trojan.

- Кнопки подключения, отмены и отключения; состояние поступает от службы Windows.
- sing-box TUN с Wintun/gVisor и локальным аутентифицированным мостом к Xray.
- Привязка исходящих сокетов к исходному адаптеру, DNS через туннель, контроль работы обоих ядер.
- Управление подключением привязано к учётной записи Windows и сохраняется при закрытии окна.
- Установка службы через `Install-Service.cmd`; интерфейс работает с обычными правами пользователя.
- Новая схема выпусков: `0.3.1`, затем `0.3.2` и далее. ZIP: `Moth-0.3.1-windows-x64.zip`.

Распакуйте весь ZIP. Один раз запустите `Install-Service.cmd` и подтвердите запрос Windows. Затем откройте `moth-desktop.exe`, импортируйте собственный сервер и нажмите «Подключить».

Это сборка для разработки без цифровой подписи. Kill switch и автоматическое переподключение после смены сети/сна ещё не реализованы. При сбое ядра/службы возвращается обычная сеть. Полная защита от утечек DNS/IPv6 и совместимость с другими VPN пока не заявлены. Существующая служба/папка установки не обновляется поверх автоматически; сведения об удалении — в README и документации службы. Linux пока не готов к пользовательскому выпуску.

Проверки Windows и Linux прошли: https://github.com/Bu11t0N/Moth-Desktop/actions/runs/43434893973. На изолированной Windows VM проверены TCP/UDP IPv4/IPv6, DNS через TUN, подключение обычного пользователя, изоляция учётных записей, переподключение и очистка при падении ядра/остановке службы.
