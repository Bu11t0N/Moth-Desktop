Moth Desktop 0.3.3 — кандидат для Windows 11 x64

Запуск
1. Распакуй ZIP полностью, сохрани папки engines и notices.
2. Отключи VPN, закрой прежнее приложение через «Выход» в трее.
   Запусти Install-Service.cmd из новой папки и подтверди Windows.
3. Открой moth-desktop.exe обычным двойным щелчком.
4. Добавь ссылку VLESS/Trojan, выбери сервер и нажми «Подключить».
5. «Подключено» появляется после HTTPS-проверки через системный туннель.

Приложение сохраняет профили в хранилище Windows DPAPI текущего пользователя.
Служба и ядра устанавливаются в Program Files/Moth Desktop. Сам интерфейс
не требует прав администратора. Для подключения нужен собственный рабочий сервер.
Крестик сворачивает Moth в трей и сохраняет VPN. Левый щелчок по значку
возвращает окно; правый открывает меню. «Отключить VPN» останавливает
подключение, «Выход» сначала отключает VPN и затем завершает приложение.
Если служба не подтверждает отключение, Moth остаётся запущен и показывает ошибку.
Изменения 0.3.3
Обычные названия экранов, действий и состояний вместо лозунгов.
В настройках — версии приложения, службы и ядер, совместимость IPC и
состояние доступных возможностей. Связь со службой проверяется отдельно от VPN.
Установщик обновляет службу 0.3.1/0.3.2 и ядра единым набором. Перед обновлением
VPN должен быть отключён. При ошибке запуска он восстанавливает предыдущую
службу. Предыдущие файлы сохраняются в Program Files/Moth Desktop.rollback-*;
профили пользователя не изменяются. Повторная установка после удаления службы
не требует ручной очистки каталога. Служба 0.3.1 совместима с GUI 0.3.3 (IPC 2).
После смены сети или сна переподключись вручную.

Ограничения версии
Это сборка для разработки без цифровой подписи. Устанавливай только пакет
из доверенного источника. Проверка хэшей не заменяет подпись издателя.
Автоматическое обновление и восстановление после сбоя питания во время
замены каталогов ещё не реализованы. Kill switch и автоматическое
переподключение ещё не реализованы. При сбое ядра/службы Windows возвращается
к обычной сети. Не заявлена полная защита от утечек DNS/IPv6; локальная сеть,
более специфичные существующие маршруты и приложения с привязкой к адаптеру
могут обходить туннель. Не используй одновременно с другим VPN.
Linux ещё не готов к пользовательскому выпуску. Windows 10 не входит
в исходную матрицу поддержки. Кандидат требует завершения сетевой и
нативной приёмки на Windows 11 перед публикацией.

Удаление службы (PowerShell от администратора из папки приложения):
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Service.ps1 -Action Remove
Файлы службы и профили сохраняются. Install-Service.cmd может установить
службу повторно без ручного удаления каталога.
