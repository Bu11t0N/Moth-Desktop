Moth Desktop 0.3.5

Optional persistent network block uses owned WFP rules on Windows and nftables rules on Ubuntu. Disconnect, Exit and process failure retain the selected block. Release it explicitly in Settings or use administrator recovery. Direct routing, per-app bypass and LAN sharing are incompatible with this option. Early Ubuntu restoration precedes NetworkManager/systemd-networkd; other managers are outside this matrix. Sudden power-loss and every cold-boot/network configuration are not claimed to be verified.

Measured engine traffic rates, bytes, session time and bounded connection summaries; optional local history with clear/reset. Structured diagnostics offer a bounded memory journal, clear and previewed export. Subscription URLs, credentials, HWID, personal paths and raw engine logs are excluded. Settings, Diagnostics, About and bundled license documents are separate pages.

Ordinary-user login startup is separate from optional automatic connection. Authenticated HTTP/SOCKS proxy-only mode creates no system TUN. Optional TUN sharing, explicit private-interface LAN client allowlists and per-user Windows/GNOME system proxy are available. Only configured applications use a proxy; OS exclusions and application support still apply. Passwords are shown on explicit request. Use trusted LANs: the client-to-Moth HTTP/SOCKS leg is not encrypted.

Disconnect, Exit and update installation restore owned system-proxy settings. Foreign edits are preserved with a recovery state. After a crash, reopen Moth and restore/check OS proxy settings before uninstalling. An unavailable application cannot restore another user's settings; manual OS recovery remains available. Native Moth downloads use an explicit private channel and do not silently fall back directly after proxy-only failure.

Hysteria2 with optional salamander, TUIC v5 and AnyTLS join existing typed profiles through the same pinned sing-box/Xray binaries. Supported URI and sing-box JSON/Clash server subsets retain certificate verification and authentication. Port hopping, arbitrary engine options, WireGuard/AmneziaWG/SSH/ShadowTLS and complete Clash/Mihomo policies remain unsupported; incompatible options fail explicitly. No full Android/provider parity is claimed.

Subscriptions/HWID consent, search/favorites/measured probes, DNS/MTU/IPv6/routing, recovery/failover, encrypted backups, themes and Russian/English are retained. Install the complete 0.3.5 package for new service features. Protected storage, IPC v2 and production updater trust are unchanged. Windows x64 requires WebView2; supported Linux is Ubuntu 24.04 x64 with systemd-resolved and a password-protected Secret Service. Windows packages use updater signatures; no Authenticode signature is claimed.
