Moth Desktop 0.3.4

Fixed corrupted Russian text in the Windows installer, including welcome, finish and uninstall pages. The license page now uses an explicitly encoded Unicode copy of the original license text.

Compatibility: IPC v2 and the existing Xray/sing-box engines are unchanged. Windows profiles remain protected by DPAPI; Linux profiles remain in Secret Service. Signed updates retain the existing production trust anchor.

Windows requires WebView2. No Authenticode signature, persistent kill switch or automatic reconnect after sleep/network changes. Linux support remains limited to the accepted Ubuntu 24.04 x64 configuration.
