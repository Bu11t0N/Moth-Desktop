Moth Desktop 0.3.6

Preview Clash/Mihomo YAML from a file or a saved subscription before choosing full-policy import or importing compatible standalone nodes. The preview lists the policy sections and flags incompatible fields. A failed refresh leaves the previously validated profile in place. A refreshed profile takes effect at the next connection.

The separate pinned Mihomo 1.19.33 worker evaluates named nodes, select/url-test/fallback groups, dialer-proxy chains, validated HTTPS and inline providers, ordered rules, RULE-SET, GEOIP and GEOSITE. Supported numeric bootstrap, HTTPS DNS, selected DNS policies and fake-IP are available. The owner can inspect active groups and choose an exit in a select group. The worker's private listeners and controller are managed by Moth.

Moth supports Clash policy profiles with its TUN and authenticated proxy modes. Moth settings control MTU, IPv6, app splitting and local rule priority in TUN. The persistent kill switch cannot be combined with a dynamic Clash policy and remains in effect until the user explicitly releases it. A possible DIRECT exit blocks private native downloads during the policy session, including VPN-only refresh.

Supported packages are Windows x64 and Ubuntu 24.04 x64. Install the complete 0.3.6 package to use the policy service. Existing Xray and sing-box profiles, protected storage and update trust remain compatible. Legacy relay, MRS, local provider files, external controllers, arbitrary listeners, scripts and unrecognized options are rejected. Profile size and supported formats are documented in docs/CLASH.md. No universal Koala or paid-provider compatibility is claimed. Windows updater signatures are distinct from Authenticode.
